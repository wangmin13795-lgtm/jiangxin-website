① 背景设置

0=背景最清晰（文字可能不好读），100=遮罩最重（文字最清楚）
给标题文字垫一块底色，背景视频再乱文字也清楚；0=不显示色块
图片/视频只是预览。最终要在网站后台或图床里把文件上传到 images/ 文件夹，路径一致才会显示。

⑤ 怎么用导出的内容（两种办法）

办法 A（推荐，用后台 Decap CMS）：

  1. 先把第 ① 步、第 ② 步用到的图片/视频文件，通过网站后台「Media」或 GitHub 上传到 images/ 文件夹（文件名要和导出里的路径一致）。
  2. 打开 你的网址/admin/ → 全站内容 → 「首页」区块。
  3. 把背景图片、背景视频、遮罩强度、文字底色块颜色/深浅填进去；点「自由图片 → Add」逐个添加，把每列对应的 水平位置/垂直位置/宽度/旋转 数字填进去（src 选那张图）。
  4. 右上角 Publish → 约 1 分钟后网站更新。

办法 B（直接改文件）：如果你愿意改 content.json，把导出结果里的 images 数组和 bgImage / bgVideo 整段替换到对应位置，上传即可。

提示：导出的「水平/垂直位置」是百分比，已按舞台自动换算，所以你在编辑器里看到的位置比例，到网站上基本一致。
